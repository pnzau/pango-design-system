Initials avatar. Circles for people (sidebar, contacts); rounded squares for row thumbnails (payment verifications).

```jsx
<Avatar initials={initialsOf('Grace Wambui')} />
<Avatar initials="MK" shape="square" size={40} background="var(--surface-chip)" color="var(--text-secondary)" />
```

Pango never shows photographic avatars — initials only.
