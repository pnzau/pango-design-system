Titles inside a page: `SectionHeading` for "Your properties" style rows, `EyebrowLabel` for the small uppercase field labels.

```jsx
<SectionHeading trailing={<StatusLegend />}>Your properties</SectionHeading>
<EyebrowLabel>EMAIL ADDRESS</EyebrowLabel>
```

Eyebrow copy is always typed in caps in the source, not lowercased by CSS.
