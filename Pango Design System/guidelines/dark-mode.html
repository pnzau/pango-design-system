What switches

Set data-theme="dark" on <html>. The grey ramp and brand palette keep their light values; only the semantic layer is remapped.

TokenLD

The one rule

A component is dark-correct because it reads tokens. A component that hardcodes a hex is the only thing dark mode breaks — so #fff becomes var(--surface-card), #0e0e0e becomes var(--text-body), and a status colour is always var(--success-bg), never #e9f7ef.

Two deliberate differences from the light theme: the accent lightens to #12b673 with an ink foreground, because white on the light green fails contrast on a dark ground; and surfaces step up from the page rather than down, so a card still reads as above its background.

No component takes a dark prop. There is no second set of components.
